# Hi, I'm Dipesh Ray

Computing Systems student in London, building at the intersection of **autonomous AI systems**, **applied cryptography**, and **cybersecurity**.

I'm interested in systems that can reason, adapt, and operate independently — and in understanding how to make them secure.

---

## What I'm Building

### 🤖 [Autonomous Brain](https://github.com/dipeshrayg/autonomous-brain)
A self-improving AI software-engineering pipeline — a boardroom of LLMs (CEO, Architects, Engineers, Security Officer, QA) that autonomously designs, builds, security-reviews, and publishes browser-runnable projects. Runs entirely on GitHub Models. Cost: $0.

> 28 projects shipped across 8 domains. Live at [dipeshrayg.github.io/autonomous-brain](https://dipeshrayg.github.io/autonomous-brain/)

### 🔐 [Interactive Cryptographic Simulator](https://github.com/dipeshrayg/2026-05-18-interactive-cryptographic-simulator)
An educational tool for exploring zero-knowledge proofs and homomorphic encryption interactively — making advanced cryptographic concepts tangible.

### 🧬 [Emergent Patterns Generator](https://github.com/dipeshrayg/2026-05-15-emergent-patterns-generator)
Cellular automata visualizer with interactive parameters — exploring how complex behaviour emerges from simple rules.

### 🛡️ [Swarm Intelligence Algorithms](https://github.com/dipeshrayg/2026-05-13-comparative-swarm-intelligence-algorithms)
Comparative analysis and implementation of swarm intelligence algorithms — ant colony optimisation, particle swarm, bee algorithms.
